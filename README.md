# Personal website

A static site (plain HTML and CSS) hosted on GitHub Pages.

- `index.html`: all page content. Edit the text here.
- `style.css`: colors, fonts and layout.
- `profile.jpg`: your photo (optional; initials are shown if it's missing).
- `cv.pdf`: your CV (optional; linked from the nav bar).

To preview it locally, open `index.html` in a browser.
